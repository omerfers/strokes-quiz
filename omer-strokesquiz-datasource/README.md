# Strokes Song Catalog — data source plugin

Serves the bundled Strokes catalog (`src/songs.json`) as a table frame, with an
album filter and a row limit in the query editor.

Full docs, run instructions and screenshots live in the
[repository README](../README.md).

```bash
npm install
npm run build
npm run typecheck
```

The catalog is generated by `node tools/build-assets.mjs` at the repo root — edit
that script rather than `songs.json`.
